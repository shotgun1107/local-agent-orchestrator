# 단계별 구현

이 디렉터리는 B0~B3 비교 대상을 서로 분리해 보존한다.

- `b0-manual/`: 사용자가 Codex 단일 세션을 직접 운영하는 기준선
- `b1-sequential/`: 단일 Worker를 순차 실행하고 자동검사하는 구현체
- `b2-parallel/`: B1이 B0 비교 게이트를 통과한 뒤 생성
- `b3-reviewed/`: B2가 B1 비교 게이트를 통과한 뒤 생성

B2와 B3는 아직 구현 조건을 통과하지 않았으므로 디렉터리를 만들지 않는다. 각 구현 단계는 다른 단계의 소스 코드를 import하지 않으며, 공통 시험 입력은 저장소 루트의 `benchmarks/`만 사용한다.
