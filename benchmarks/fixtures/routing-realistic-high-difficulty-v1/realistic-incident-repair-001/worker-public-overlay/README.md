# Evidence-bound runtime incident repair

Repair the model-free Windows runtime-boundary implementation by following the
eight Tasks in `benchmark-run.yaml`. The public incident observations are under
`profile-i/evidence/`; the public invariants and record formats are under
`profile-i/requirements/`.

`benchmark_checks/`, `.orchestrator/`, the public observations, requirements,
this README, and `benchmark-run.yaml` are protected challenge files. Public
checks confirm only declared work and public invariants. Terminal evaluation is
performed separately.
