# INC-2025-02-14-CHECKOUT

## 확인된 사실

- [CLM-001] rel-204 배포는 09:04에 시작되어 09:11에 완료되었다.
- [CLM-002] 롤백은 09:31에 시작되어 09:34에 완료되었고 오류율은 09:36에 정상 범위로 돌아왔다.
- [CLM-003] 두 독립된 관찰에서 장애 구간의 데이터베이스 p95 지연 시간이 정상 범위였다고 기록했다.

## 상충

- [CLM-004] 오류 증가 시작 시각은 온콜 로그의 09:16과 원시 지표의 09:14가 상충한다.

## 미확인

- [CLM-005] rel-204의 인증 재시도 변경이 근본 원인인지는 확인되지 않았다.
- [CLM-006] 인증 업스트림 지연과 오류 증가의 인과관계는 확인되지 않았다.

## 권고

- [ACT-001] 원시 오류 지표와 온콜 로그의 시계 및 집계 구간을 대조해 시작 시각을 확정한다.
- [ACT-002] rel-204의 인증 재시도 변경을 재현 환경에서 단독으로 부하 시험한다.
- [ACT-003] 결제 요청과 인증 업스트림 호출을 잇는 상관관계 ID와 지연 시간 계측을 추가한다.
