# 다음 연구·개발 범위

## 현재 우선순위

개발 규약·문서 경계·Git 이력 정비는 완료했다. 다음 기능개발·연구 범위는 아직 지정하지 않았다.
원격 대표본은 main이다. 기존 PC의 옛 브랜치는 미전송 변경을 보존하고 새 이력으로 별도 전환해야 한다.
절차는 docs/operations/workspace-portability.md, 전송 commit·환경·미전달 자료는
기존 동기화_인수인계.md의 SYNC:AUTO가 정본이다.

## 이후 기능개발·연구

- 감사 수선과 2026-10-01 인수 안내 교정은 종료했다. 다음 기능개발 또는 연구 질문은 아직 지정하지 않았다.
- B2 병렬·B3 Reviewer·새 비교 experiment·외부 pilot은 보류다. 필요성과 완료 조건을 정한 뒤 별도 범위로 착수한다.
- 기존 정상·실패·중단 회차는 보존 자료다. 다음 실험의 입력·환경·승인은 기존 결과와 구분한다.
- 다른 PC의 환경·인증·외부 원본 전달은 Git 정비와 별개이며 아직 미확인이다.

개발·검증·실제 실행·PC 전환 절차는 연결된 저장소 CONTRIBUTING.md와
docs/operations/workspace-portability.md를 참조한다. 이 문서에는 AI의 세션별 진행 일지를 누적하지 않는다.
